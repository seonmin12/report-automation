# Data Dictionary

이 프로젝트가 다루는 3개 입력 파일의 컬럼 정의입니다. 컬럼명은 [config.py](../config.py)의
상수(`COL_*`)와 정확히 일치하며, 검증 로직(`src/validate.py`, `src/compare.py`,
`src/aggregate.py`)과 웹 업로드(`web/app.py`)가 이 스키마를 그대로 기준으로 삼습니다.

> 모든 값은 100% 더미(가상)이며, 실제 회사명/상품명이 아닙니다.

## 1. 매핑 기준표 (`product_mapping.xlsx`)

요금제/상품 코드와 사업자, 사용 여부를 정의하는 마스터 데이터입니다.

| 컬럼명 | 업무 의미 | 설명 | 예시 |
|---|---|---|---|
| 상품코드 | 상품 식별자 | 요금제/상품을 구분하는 고유 코드 | `PRD010` |
| 상품명 | 상품 표준명 | 매핑표 기준 표준 상품명 (RAW/포털의 상품명과 다르면 명칭불일치 이슈) | `5G 데이터 010` |
| 요금제유형 | 상품 분류 | 5G 데이터 / LTE 데이터 / 음성+데이터 결합 / 청소년 요금제 / 시니어 요금제 | `5G 데이터` |
| 사업자코드 | 사업자 식별자 | 이 상품을 운영하는 MVNO 사업자 코드 | `MVN01` |
| 사용여부 | 상품 활성 상태 | `정상`이면 판매 중, `비활성`이면 서비스 종료 상품 | `정상` |
| 매핑등록일 | 매핑 등록일 | 매핑표에 이 상품코드가 등록된 날짜 | `2025-11-15` |
| 비고 | 비고 | 중복 등록/서비스 종료 등 관리용 메모 (선택) | `중복 등록` |

**필수 컬럼** (없으면 업로드 검증에 실패): 상품코드, 상품명, 사업자코드, 사용여부, 매핑등록일

## 2. RAW 거래 데이터 (`raw_transactions.csv`)

실제 가입/해지 거래가 발생할 때마다 한 행씩 쌓이는 원천 데이터입니다.

| 컬럼명 | 업무 의미 | 설명 | 예시 |
|---|---|---|---|
| 거래ID | 거래 식별자 | 거래 1건당 고유 ID | `TXN000123` |
| 처리일자 | 거래 발생일 | 신규/해지가 처리된 날짜 (당월 집계 필터링 기준) | `2026-07-19` |
| 사업자코드 | 사업자 식별자 | 거래가 발생한 MVNO 사업자 코드 | `MVN01` |
| 상품코드 | 상품 식별자 | 거래 대상 상품코드 (매핑표에 없으면 매핑누락 이슈) | `PRD010` |
| 상품명 | 거래 시점 상품명 | RAW에 기록된 상품명 (매핑표 표준명과 다르면 명칭불일치 이슈) | `5G 데이터 010` |
| 거래유형 | 거래 종류 | `신규` 또는 `해지` | `신규` |
| 선후불구분 | 요금 납부 방식 | `선불` 또는 `후불` | `후불` |
| 채널 | 가입 채널 | `온라인` / `오프라인` / `제휴채널` | `온라인` |
| 등록시각 | 시스템 등록 시각 | 거래가 시스템에 기록된 타임스탬프 | `2026-07-19 14:32:07` |

**필수 컬럼**: 거래ID, 처리일자, 사업자코드, 상품코드, 상품명, 거래유형

## 3. 포털 실적 (`portal_performance.xlsx`)

포털에서 집계되어 내려받는 사업자/상품 단위 월간 실적입니다. RAW를 직접 집계한 값과
대사(비교)하는 대상입니다.

| 컬럼명 | 업무 의미 | 설명 | 예시 |
|---|---|---|---|
| 사업자코드 | 사업자 식별자 | MVNO 사업자 코드 | `MVN01` |
| 사업자명 | 사업자명 | 사업자 코드에 대응하는 이름 | `알뜰통신A` |
| 상품코드 | 상품 식별자 | 집계 대상 상품코드 | `PRD010` |
| 상품명 | 포털 상품명 | 포털에 표시된 상품명 (RAW/매핑표와 다르면 명칭불일치 이슈) | `5G 데이터 010` |
| 신규건수 | 신규 가입 건수 | 해당 사업자/상품의 당월 신규 건수 | `41` |
| 해지건수 | 해지 건수 | 해당 사업자/상품의 당월 해지 건수 | `15` |
| 순증건수 | 순증 가입자 | 신규건수 − 해지건수. 포털-RAW 대사의 핵심 비교 지표 | `26` |

**필수 컬럼**: 사업자코드, 사업자명, 상품코드, 상품명, 신규건수, 해지건수, 순증건수

## 참고

- 실제 필드 목록과 검증 시 KeyError 방지를 위한 필수 컬럼 체크는 `web/app.py`의
  `REQUIRED_COLUMNS`에 이 문서와 동일하게 정의되어 있습니다.
- 각 컬럼에 적용되는 검증 규칙(무엇을 이상으로 판단하는지)은 [validation_rules.md](validation_rules.md)를 참고하세요.
